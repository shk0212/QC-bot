# QC-BOT: Integrated Semiconductor Quality Analysis System

**QC-BOT**은 반도체 품질관리(QC) 엔지니어를 위한 AI 기반 통합 분석 대시보드입니다. 산업용 미니멀리즘 디자인을 채택하여 복잡한 공정 데이터를 직관적으로 관리하고 분석할 수 있도록 설계되었습니다.

## 🚀 Key Features

### 1. Root Cause Analysis (불량 원인 분석)
- 공정 노드 및 결함 증상을 기반으로 한 정밀 FA(Failure Analysis) 리포트 생성
- 20년 경력의 수석 엔지니어 페르소나를 활용한 전문적인 기술 분석

### 2. Quality Mentoring (품질 멘토링)
- 엔지니어링 지식 베이스를 바탕으로 한 1:1 기술 상담 챗봇
- 실무 가이드 및 SEMI 표준 기반의 답변 제공

### 3. Data Diagnosis (장비 데이터 진단)
- ALD 장비의 실시간 파라미터(온도, 압력, 유량) Spec 준수 여부 판정
- OOS(Out of Spec) 즉각 알림 및 공정 안정성 체크

## 🛠 Tech Stack
- **Language**: Python 3.x
- **Framework**: Streamlit
- **AI Engine**: Google Gemini 1.5 Pro/Flash
- **UI/UX**: Industrial Minimalist Template (High Contrast Design)

## 📦 Installation & Run
1. Repository 클론:
   ```bash
   git clone [Your-Repo-Link]
   cd qc-bot
   ```
2. 라이브러리 설치:
   ```bash
   pip install -r requirements.txt
   ```
3. 어플리케이션 실행:
   ```bash
   streamlit run sse_web.py
   ```
